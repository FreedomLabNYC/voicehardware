# Hardware and tool references

## Current 3.97-inch Wi-Fi concept
- [Waveshare ESP32-S3-ePaper-3.97, SKU33552](https://www.waveshare.com/esp32-s3-epaper-3.97.htm?sku=33552)
- [Manufacturer documentation, dimensions and component images](https://docs.waveshare.com/ESP32-S3-ePaper-3.97)
- [Schematics / resources](https://docs.waveshare.com/ESP32-S3-ePaper-3.97/Resources-And-Documents)
- [Manufacturer rear component photograph](https://docs.waveshare.com/assets/images/ESP32-S3-ePaper3.97-details-intro-47c6d645fb8704b42d4fef9cb0e7b857.webp)

Sourced board outline: 99.50 × 60.00 mm, R2; active screen: 86.40 × 51.84 mm. Proposed enclosure: 112 × 84 × 23 mm. Board thickness, package heights, apertures, controls, wiring and acoustic paths remain conceptual. No measured fit, manufacture, electrical, thermal or RF validation. No battery selected or modeled. Wi-Fi/USB only; physical PTT integration remains unresolved. TG28 versus AXP2101 is an unresolved board-revision/source conflict.

## Software
- [Schematik](https://www.schematik.io/) — AI hardware IDE for Arduino, ESP32, and Raspberry Pi Pico. Desktop 0.2.0 is installed on this Mac (`/Applications/Schematik Desktop.app`, Developer ID, notarized). Web app: https://www.schematik.io/app. Download: https://www.schematik.io/download. Related guide, not our hardware: [Hermes voice satellite](https://www.schematik.io/projects/build-a-hermes-voice-satellite). Generated wiring is not a fit test.
